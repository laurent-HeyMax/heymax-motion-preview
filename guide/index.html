01 · Logo

Four marks, one order.

When in doubt, use the main gradient logo. The M letterform and the monogram are restricted: ask the HeyMax brand team before using them.

    Quick decision

    • 1Public-facing → Main logo, Gradient
    • 2Small, one-colour or busy background → Main logo, Flat
    • 3Merch or in-app animation → M letterform (restricted)
    • 4Name card, watermark, tiny → Monogram (restricted)
    • ?Unsure → Main logo, Gradient, or ask design.

        08 · Motion

        Taking off.

        A motion language for HeyMax. Things rise and move forward, like a plane leaving the ground: calm, sure, never bouncy.

        Context

        HeyMax makes a lot of motion: social stories, partner spotlights, event screens, the website and the app. Each piece used to be built on its own, so the brand moved in many different ways. We did not need one more asset. We needed one way of moving.

        Outcome

        One motion language with five principles, one signature move and a short list of durations and curves. It is built in Cavalry as one master file and one library script, so every piece moves the same way, and a new piece starts from a template, not from zero.

        Principles

          Signature behaviour

          The lift.

          Type and objects rise from behind an invisible line. No fade, no tilt. They travel 115% of their own height, so they start fully hidden. They land with a long soft stop, drift slowly while they hold, then take off upward.

          • 1Enter dur-l · 24f lift
          • 2Hold drift · 14 px slow and constant
          • 3Exit dur-s · 12f depart upward, 1f stagger
